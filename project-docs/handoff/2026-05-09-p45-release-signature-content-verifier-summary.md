# P45 Release Signature Content Verifier Summary

Date: 2026-05-09

## Goal

Strengthen the release directory verifier so `.sig` sidecars are cryptographically checked, not only present.

## Changes

- Updated `src-tauri/src/release_gate.rs`:
  - parses `RSA-CSP-BLOB-SHA256` public key files generated by `scripts/New-ReleaseManifest.ps1`
  - verifies `latest.json.sig` and every manifest asset `.sig` against actual file bytes
  - rejects unsupported signature algorithm values with `release.signature_algorithm_unsupported`
  - rejects malformed public keys with `release.public_key_invalid`
  - rejects invalid signatures with `release.latest_json_sig_invalid` or `release.asset_sig_invalid`
  - rejects mismatched signatures with `release.latest_json_sig_mismatch` or `release.asset_sig_mismatch`
  - adds a Windows-only compatibility fixture that invokes `scripts/New-ReleaseManifest.ps1`, then validates the generated staging directory through the Rust verifier
- Updated dependencies:
  - `base64`
  - `rsa`
  - `rand` as a dev dependency for deterministic test fixtures
- Updated release/eval docs:
  - `project-docs/status.md`
  - `PLANS.md`
  - `docs/testing/eval-harness.md`
  - `docs/testing/release-and-regression-gates.md`
  - `project-docs/handoff/2026-05-09-rc1-readiness-audit.md`
